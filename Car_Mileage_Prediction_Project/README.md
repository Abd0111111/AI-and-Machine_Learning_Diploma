# Car Mileage Estimation (MPG Prediction)

Predict fuel efficiency (miles per gallon) based on engine and vehicle features.

## Dataset  
Includes engine size, vehicle weight, number of cylinders, and fuel type.

## Task  
Build a regression model to estimate miles per gallon (MPG) from the given features.

## Folder Structure  
- dataset/: raw and cleaned data files  
- notebooks/: step-by-step Jupyter notebooks  
- outputs/: saved figures, metrics, and model files  

## Notebooks Overview  
1. Data exploration and visualization  
2. Data cleaning and feature preparation  
3. Model training and saving  
4. Model evaluation and analysis  

## Requirements  
- pandas  
- scikit-learn  
- matplotlib  
- seaborn  

## Usage  
Run notebooks in order to reproduce results.
